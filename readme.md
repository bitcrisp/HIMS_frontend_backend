# Hospital Information Management System (HIMS)

This project is built to learn how a Hospital Management System works in real-world scenarios using practical concepts. It includes a frontend developed with Angular and a backend built using C#.

## Description

The application currently has two main components:
- Welcome Page
- Patient Page

The Patient page includes form validation and sends patient data to the backend API.  
On the backend, the data is stored as a patient list (array), and validation is performed to prevent null or invalid values.

## Getting Started

### Dependencies

#### Frontend
- Node.js v18
- Angular v19

#### Backend
- .NET SDK v10
- Visual Studio 2022

## Installation

### Step 1: Clone the Repository

```
https://github.com/vikky2810/HIMS_frontend_backend.git

```



### Step 2: Backend Setup (C# / .NET)

1. Open Visual Studio 2022.
2. Open the solution at:  
   `Server/HIMS/HIMS`
3. Right-click the solution and restore NuGet packages.
4. Build and run the solution.


### Step 3: Frontend Setup (Angular)

1. Navigate to the Angular project directory:  
   `angular/HIMS/`

2. Install dependencies:  
   `npm install`

3. Install Angular CLI (if not already installed):  
   `npm install @angular/cli`

4. Start the development server:  
   `ng serve`

---


> Start the backend first, then run the Angular frontend.
